# Список задач

Простое приложение на React + TypeScript (Vite): добавление, выполнение, удаление и фильтрация задач. Список сохраняется в `localStorage`.

Время на задание: около 45 минут.

## Запуск

Нужны Node.js и npm.

```bash
npm install
npm run dev
```

Откройте адрес из терминала (обычно `http://localhost:5173`).

## Сборка

```bash
npm run build
```
